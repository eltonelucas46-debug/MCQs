Assessment briefing

This examination assesses four areas of organic chemistry using short answers, naming, calculations, comparisons and structure tasks. It is designed for practice and revision, not as a formally proctored university examination.

Rules and marking
  • 30 questions; 60 marks in total (2 marks per question).
  • 60-minute countdown; the test submits automatically at zero.
  • Answers are saved in this browser on this device, where browser storage is available.
  • Automatic marking accepts common answer variants for supported text answers. Some chemically equivalent names or detailed explanations may not be recognised.
  • The drawing board lets you place carbon atoms and connect them with single, double or triple bonds. It is a basic sketch tool, not a full chemical editor; drawings are saved for review but are not chemically validated automatically.
  • Complex written explanations receive rubric-based partial credit only where a clear keyword rubric is provided. Review the feedback rather than treating the automated score as infallible.
Internet and API note
This is a self-contained single-file website and uses no AI API, account, server or paid service. Core features work offline after the file is saved locally. No external chemical editor is loaded; the simple SVG drawing board is built into this file. Printing to PDF uses your browser's print dialogue.
